| # | 机制 | 位置 | 为什么值得吸收 |

| D1 | **路由前缀自适应** | `comfyui.js:65-113` | ComfyUI 同时提供 `/xxx` 与 `/api/xxx`，但**只转发 `/api/*` 的反向代理**会让裸路由 404。首次请求探测一次并缓存到进程级 `Map`（键是 baseUrl）。 |
| D2 | **/upload/image 必须 multipart** | `comfyui.js:175-184` | 直接 POST 原始字节 → HTTP 400。必须 `FormData` + 字段名 `image` + `overwrite=true`。**这条不踩一次不会知道。** |
